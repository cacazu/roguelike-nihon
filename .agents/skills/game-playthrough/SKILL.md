# 攻略と操作記録

実プレイの依頼では、調べた立ち回りを実際の判断へ使い、指定された勝利条件まで進める。攻略の説明だけを求められた場合は説明にとどめる。

## 試行の条件

作品・原作の版・ビルド、seed、勝利条件、死亡・ロード・新規試行の制限、全操作記録と録画の要否を依頼に合わせる。指定seed・記録がある場合はそれを使い、事前記録に基づく判断を明示する。未指定なら再現可能な条件を選んで示す。別の版や実装の記録を無条件に再生しない。

通常のゲームと入力経路を使う。fixture、無敵化、状態編集、RNGの差し替え、未公開マップ・未識別品の内部値を攻略手段にしない。作品の既存ブラウザー接続を利用し、表示はスクリーンショットでも確認する。録画は依頼がある場合に作る。

## 判断に使う攻略

対象版の公式マニュアル・原作コードと英語圏を含む攻略を検索し、該当本文を読む。出典・対応版・使う判断を残す。品物・敵の数値だけでなく、序盤から終盤・帰還・勝利まで、戦う／逃げる／探索する／資源を使う条件を調べる。

攻略の立ち回り、公式資料や現行コードで確認した効果、今回の観測を区別する。先の敵と特殊能力、装備と位置取り、退路、回復・食料・逃走手段、未識別品を試す条件、目的物取得後の帰還へ具体化する。

## 観測して操作する

操作前に公開された地図、HP・空腹・状態、装備・持ち物、最新ログと入力待ちを見る。目的と中止条件を決める。危険な状況は一操作ごとに結果を確認し、安全を確認できた区間だけ連続入力や走行を使う。敵、被弾、状態変化、移動停止、別の入力待ちで止める。

品物・方向・手・文字・確認等は実際の候補と文脈に従う。コマンドを押すだけで済ませず、選択・効果・地図への復帰を確認する。敵の連続攻撃や特殊効果、回復・逃走が間に合う条件を見積もり、理由のない殴り合いや未識別品の使用を避ける。

記録を使う再攻略でも、その時点の公開状態・待ち・結果を照合する。差が出た操作で止めて再計画する。不具合は前後の操作と状態を記録し、修正も依頼されているなら原因を調べる。修正前後の試行を分け、条件が変わったプレイを元の成功へ数えない。

## 操作記録と成功判定

全操作記録・集計・再攻略には [記録形式](references/recording.md) を使う。送った入力、送信前の待ち、前後の公開状態、実際の結果を逐次残す。移動以外の品物・方向・取消・More・保存・ロードも対象に含める。送信数、消費済み入力、ゲームターンを混同しない。

戦闘・資源使用・装備・進路変更等の判断には現在の観測と先の脅威を結び付けた理由を添える。単調な安全移動へ説明を繰り返さない。失敗試行も残し、無断ロードや試行の隠蔽をしない。新規試行が許されるなら別IDにし、成功試行と全試行の結果を分ける。

作品の目的物・帰還・エンディング等を最後まで確認する。階への到達、終了ウインドウや入力列の終端だけでクリアとしない。報告は作品・版・seed・試行ID、実際の勝利結果、死亡・ロード実数と記録先を示す。未達なら到達点・失敗理由・残る条件を示す。集計は逐次記録から件数順に出し、動画を求められた場合は完成した動画の再生と内容を確認する。

作品の入口は [親AGENTS](../../../AGENTS.md) と [作品一覧](../../../README.md)。対象のAGENTS、起動・操作・原作仕様と検証手順を読み、過去のローカル記録は実在するファイルと対応ビルド・条件を照合して使う。
