# Brogue Webの境界

原作はBrogue: Community Edition 1.15.1。取得元・日本語化は [locales/README.md](../locales/README.md)、実行は [README](../README.md)、素材は [SOURCES](../web/assets/SOURCES.md) を参照する。

## 状態と責務

| 場所 | 所有する内容 |
|---|---|
| `src/brogue/`・`src/variants/` | 原作の生成、移動、戦闘、可視性、ターン、乱数、録画・保存serializer、原作ウインドウの公開内容 |
| `src/platform/browser-platform.c` | `brogueConsole` の接続、公開済みセルのコピー、Rustへの入出力待ち、修飾キーの観測 |
| `rust/src/input.rs` | 物理キー・タッチ操作から原作入力への変換、待ち種別と候補の検証 |
| `rust/src/presentation.rs` | 公開セルの描画、3表示の選択、ゲーム別の記号と画像の設定 |
| `rust/src/browser.rs` | ブラウザーの操作部品、画面サイズ、文字入力、保存ファイル、セッションの寿命 |
| [`rust-common`](../../rust-common/README.md) | フォント・PNG・図形を描画してRGBAを返すゲーム非依存API |
| `web/host.js`・`web/library.js` | Wasmの初期化、バイト列・イベント・PromiseとブラウザーAPIの薄い接続 |

原作のCが公開した画面をRustが描画する。Rustが非公開の地形・怪物・未識別品をゲーム内部から探索しない。共通クレートには盤面寸法、Brogueのglyph値、コマンド、翻訳、保存形式を置かない。両作品は共通クレートへ直接依存し、旧Rogue専用rasterクレートは持たない。

## 描画の契約

盤面は100列×34行。`frame` は行優先の符号付き32bit整数をコピーして渡す。各セルは10値で、raw glyph、公開Unicode、前景RGB、背景RGB、環境glyphフラグ、予約値の順。色は0～100。Wasmのメモリーを借用し続けず、Rust側で所有するコピーへ取り込む。 frameには別引数で上部メッセージ鏡像の保持状態も渡す。Fと発見一覧の原作表示ownerが開始／復元し、Rustは合成済みmodal文字を別メッセージ欄へ転記しない。入力待ちkindや英文から表示状態を推測しない。状態だけの変更もC側でpublishし、Rust側で適用する。入れ子は元値を保存して戻す。セルABIの予約値は変更しない。

日本語glyphは `LOCALIZED_GLYPH_BASE` を加えたUnicodeで、baseだけのセルは全角文字の後半。全背景を描いた後に前景を描き、後半セルが先行文字を消さない。通常の文字UIは3表示で共通とし、地形・品物・怪物の画像対応は作品固有設定で明示する。

Originalの植物・火・護符・指輪・トーテム・魔力記号は、原作SDLのfontIndexに対応する同梱atlasの字体を単色マスクとして使い、Cの公開前景色と背景色を保持する。植物U+2648は `0x84`、火U+22CFは `0x83` に対応し、全対応の正本は [presentation.rs](../rust/src/presentation.rs) の `ORIGINAL_FONT_GLYPHS` とする。同梱フォントの欠字を避け、カラー絵文字の固定色により植物や指輪のC色を失わない。マスクの黒い裏地は透明度へ変換し、倍率に合わせて被覆率を縮小してセル内へ描く。

この対応はOriginalかつraw値が原作ゲームglyph範囲内の公開Unicodeに限る。盤面とsidebar内の原作記号へ同じ字体・色を使い、通常の文字UIや日本語glyphには適用しない。共通描画APIへゲーム別設定を入れず、表示切替でも公開セルを変更しない。

表示切替・拡縮・スクロール・プレイヤー位置への表示移動は、Rust側にある公開snapshotだけを再描画する。Cのキー入力、ターン更新、乱数処理を呼ばない。ドット絵は原作atlas、イラストは生成atlasを使い、足りないゲームglyphを別モードへ黙って戻さない。

## 入力の契約

同期処理の原作が入力を必要とする位置でAsyncifyにより休止し、実際のイベントが来たときだけ再開する。空キューをEscなどの仮キーにしない。イベントは原作のtype、param1、param2、Ctrl、Shiftの5値。

入力待ちの正本は `src/platform/BrowserIO.h`。通常コマンド、対象・方向、品物、確認、文字、メニュー、確認済み送り、タイトルを区別し、文字数上限、取消可否、公開されたキー候補を渡す。原作の入力所有者がdescriptorを設定し、入れ子の待ちが終わると直前のdescriptorへ戻す。Rustは画面の英文・日本語の逆解析で待ちを判定しない。

PCのキーとタッチ部品は同じRust入力処理を通す。品物候補・確認・文字入力の待ちでは、その待ちに関係する操作を出す。入力イベントの再変換や、別セッションに残ったイベント・Promiseの流用をしない。タッチのShiftは通常コマンド・カーソルの英字を物理キーと同じ大文字にし、コマンド・カーソル・対象・録画待ちのTabをWeb物理Shift+Tabと同じ原作キーへ変換する。品物などのモーダル候補の英字は公開された値を保つ。別セルへの盤面タップで照準が移動した場合は、原作どおりEnterまたは同じセルへの再タップで確定する。

原作のSpace/Escによる確認待ちと任意キー待ち、地図カーソル待ち、録画再生待ちを区別する。候補は原作が受理するテンキー・大文字移動・Tab/Shift+Tab・取消も含める。メニューと統計画面のSpace/Esc、履歴のスクロール、付替え先の英字も原作の入力所有者から公開する。録画再生では速度・一時停止・移動・終了など、その版の原作に到達可能な操作を提示し、通常プレイの操作盤を表示しない。物理入力で中断したpauseのイベントは、次の待ちに変わっても原作同様に保持する。マウス移動だけはpauseの割込み指定を守り、タッチのパンをゲームのクリックへ変換しない。

GはWebの3表示を循環し、倍率・全画面・撮影もRustの環境操作として扱う。撮影は最新のCanvasをPNGとしてブラウザーへダウンロード要求する。OSへの保存完了とは区別する。右クリック、テンキーのNumLock状態、文字欄のEsc、タッチのCtrl/Shift操作を同じ原作イベントへ接続する。原作のhybrid表示やSDLのウインドウ管理との対応範囲は [機能の基準](FEATURES-ja.md) を参照する。

## 保存と配布

Cの保存ファイルと録画の形式を保持する。ブラウザー側はそのファイルの読み書きと、新しいゲームinstanceへの復元を担当する。Wasmのポインターや呼出しスタックを保存形式にしない。保存の検証はファイル取得だけで完了とせず、新instanceでの復元と次の操作まで実行する。

保存対象は`.broguesave`・`.broguerec`と、CE・Rapid・Bulletそれぞれの原作スコア／プレイ履歴ファイル。再開操作は`.broguesave`だけを受け付ける。書出しと復元の両方で64ファイル、各8MiB、コンテナ32MiBの同じ制限を使う。容量やブラウザー保存の失敗時は既存の保存コンテナを置き換えず、画面へエラーを示す。

Web配布には `web/` とproductionの `build/` を含める。`web/licenses/THIRD-PARTY.txt` はC原作、実際のCargo依存、Rust標準ライブラリー、wasm-bindgen生成JavaScript、EmscriptenのC/JavaScriptランタイム、画像・フォントの必要な通知原文を保持する。生成画像のプロンプト・出典・利用条件は素材一覧を正本とする。変更した原作ソースと各ファイルの著作権表示を保持し、対応ソースをゲームからGitHubへ辿れるようにする。

検証専用の `game-check.js`・`game-check.wasm` は配布しない。productionにゲーム状態の検証exportを混ぜない。通常ビルドと検証ビルドは別名で生成する。

## 変更時の受け入れ条件

初期タイトルからの開始、通常移動、品物選択、方向、確認・取消、文字入力、保存復元後の次操作を、PCキーとスマートフォンのタッチから実行する。PC・縦向き・横向きの画面で描画と操作可能範囲を確認する。3表示の実画像を比較し、切替・拡縮でCのターン・substantive乱数・位置・HPが不変であることを専用ビルドで照合する。

固定シードと同じ消費済み入力を原作比較の基準とする。Rust単体検査、実Cゲーム検査、Playwrightでのブラウザー操作、スマートフォン実機での操作は別の証拠として扱う。各実行入口は [tests/README.md](../tests/README.md) にまとめる。
